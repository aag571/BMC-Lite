# 集成状态与运行限制

采样通过 Device 进入阈值状态机。状态迁移写入日志及 SEL，直接评估规则，同时向事件总线发送异步通知。规则产生恢复请求后提交 Worker。任务复制传感器 ID、动作名称及路径，不引用可能被热加载销毁的传感器对象。恢复结果写入日志、SEL 和事件总线。退出先排空 Worker，再停止总线，最后销毁存储。

恢复只允许 increase_fan 和 inspect_device。前者需要 --enable-actions 才写 PWM，后者仅确认检查请求。不再同时执行旧的直接 PWM 路径。规则仍按状态变化事件计数，不是按每次采样确认；规则文件不支持热加载。通配规则的状态尚未按传感器分离。

HTTP 只监听本机，限制为 16 个处理线程、32 个待处理连接及 5 秒连接超时。最多保留最近 4096 条可读 SEL 记录用于响应，仍扫描整个文件，未提供增量缓存或分页。它不是标准 Redfish/IPMI 服务。

SEL 内存容量受限，磁盘文件仍无限追加；没有 CRC、fsync 或断电保证。恢复引擎内部锁仍使动作串行执行。任务没有取消和超时，Worker stop 不支持任务内部或多个线程同时调用。尚不能宣称生产级完成。
